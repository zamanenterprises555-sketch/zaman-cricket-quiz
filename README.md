# Zaman Cricket Quiz

ക്രിക്കറ്റ് രീതിയിലുള്ള മൾട്ടിപ്ലെയർ ക്വിസ്. ലൈവ്: https://zamanenterprises555-sketch.github.io/zaman-cricket-quiz/

## ഫയലുകൾ
| ഫയൽ | എന്താണ് |
|---|---|
| `questions.js` | **ചോദ്യങ്ങൾ മാത്രം.** പുതിയ സെറ്റ് ചേർക്കാൻ ഇത് മാത്രം മാറ്റുക (മുകളിലെ കുറിപ്പ് നോക്കുക). |
| `engine.js` | കളിയുടെ നിയമങ്ങൾ (റൺസ്, വിക്കറ്റ്, സ്ട്രൈക്ക്, ഓവർ, ഇന്നിംഗ്സ്, വിജയി). സോളോയും മൾട്ടിപ്ലെയറും ഇതേ നിയമം ഉപയോഗിക്കുന്നു. |
| `app.js` | സ്ക്രീനുകൾ, Firebase റൂം, ഓട്ടോ റീജോയിൻ, ടൈമർ. |
| `style.css` | ഡിസൈൻ. |
| `sw.js` | ഓഫ്‌ലൈൻ / ആപ്പ് ആയി ഇൻസ്റ്റാൾ. ഓരോ റിലീസിലും `VERSION` മാറ്റുക. |
| `tests/` | `node tests/engine-rules.test.js` — നിയമങ്ങളുടെ ടെസ്റ്റ്. |

## റൺസ് (ഒരു പന്തിന്റെ സമയത്തിന്റെ ഭാഗം അനുസരിച്ച്)
| സമയം | റൺസ് |
|---|---|
| 0–20% | 6 |
| 20–40% | 4 |
| 40–60% | 3 |
| 60–80% | 2 |
| 80–100% | 1 |
| സമയം കഴിഞ്ഞാൽ | ഔട്ട് |
| ഉത്തരം തെറ്റിയാൽ | ക്ലീൻ ബൗൾഡ് |
| ബൗളറുടെ ഉത്തരം തെറ്റിയാൽ | +1 എക്സ്ട്രാ (പന്ത് എണ്ണും) |

OPTIONAL = 10 സെക്കൻഡ്, ONE WORD = 1 മിനിറ്റ്, MINIMUM 3 SENTENCES = 3 മിനിറ്റ്, MINIMUM 5 SENTENCES = 5 മിനിറ്റ്, PICTURE IDENTIFYING = 5 മിനിറ്റ്.

## v2.1
- ബൗളർ തെറ്റിയാൽ: +1 എക്സ്ട്രാ, പന്ത് എണ്ണില്ല, **ഇതേ ചോദ്യം** ശരിയാകും വരെ (ഓരോ തെറ്റിനും +1).
- ഓരോ കളിക്കാരനും സ്വന്തം «തിരിച്ചുവരാനുള്ള ലിങ്ക്» (🔗) — രഹസ്യ ടോക്കൺ; റൂമിൽ അതിന്റെ SHA-256 മാത്രം സൂക്ഷിക്കുന്നു.
- ടോസ്, സൂപ്പർ ഓവർ (സ്കോർ ഒപ്പമായാൽ; 1 ഓവർ, 2 വിക്കറ്റ്, ഉപയോഗിക്കാത്ത ചോദ്യങ്ങൾ; പരമാവധി 3), ഓഫ്‌ലൈൻ കളിക്കാരനെ മാറ്റൽ, കളി കഴിഞ്ഞ് തെറ്റിയ ചോദ്യങ്ങളുടെ റിവ്യൂ, റൂം ചാറ്റ് (💬).
- 24 മണിക്കൂർ കഴിഞ്ഞ റൂമുകളും ചാറ്റും ആപ്പ് തുറക്കുമ്പോൾ തനിയെ മായ്ക്കും.

## Firebase സുരക്ഷാ നിയമങ്ങൾ (database.rules.json)
Firebase Console → Realtime Database → Rules → `database.rules.json`-ലെ ഉള്ളടക്കം പേസ്റ്റ് ചെയ്ത് **Publish**.
(അല്ലെങ്കിൽ: `npm i -g firebase-tools && firebase login && firebase deploy --only database --project zaman-6587f`)
