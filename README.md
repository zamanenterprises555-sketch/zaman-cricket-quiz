# Zaman Cricket Quiz

ക്രിക്കറ്റ് രീതിയിലുള്ള മൾട്ടിപ്ലെയർ ക്വിസ്. ലൈവ്: https://zamanenterprises555-sketch.github.io/zaman-cricket-quiz/

## ഫയലുകൾ
| ഫയൽ | എന്താണ് |
|---|---|
| `questions.js` | **ചോദ്യങ്ങൾ മാത്രം.** പുതിയ സെറ്റ് ചേർക്കാൻ ഇത് മാത്രം മാറ്റുക (മുകളിലെ കുറിപ്പ് നോക്കുക). |
| `engine.js` | കളിയുടെ നിയമങ്ങൾ (റൺസ്, വിക്കറ്റ്, സ്ട്രൈക്ക്, ഓവർ, ഇന്നിംഗ്സ്, വിജയി). സോളോയും മൾട്ടിപ്ലെയറും ഇതേ നിയമം ഉപയോഗിക്കുന്നു. |
| `app.js` | സ്ക്രീനുകൾ, Firebase റൂം, ഓട്ടോ റീജോയിൻ, ടൈമർ. |
| `style.css` | ഡിസൈൻ. |
| `sw.js` | ഓഫ്‌ലൈൻ / ആപ്പ് ആയി ഇൻസ്റ്റാൾ. ഓരോ റിലീസിലും `VERSION` മാറ്റുക. |
| `tests/` | `node tests/engine-rules.test.js` — നിയമങ്ങളുടെ ടെസ്റ്റ്. |

## റൺസ് (ഒരു പന്തിന്റെ സമയത്തിന്റെ ഭാഗം അനുസരിച്ച്)
| സമയം | റൺസ് |
|---|---|
| 0–20% | 6 |
| 20–40% | 4 |
| 40–60% | 3 |
| 60–80% | 2 |
| 80–100% | 1 |
| സമയം കഴിഞ്ഞാൽ | ഔട്ട് |
| ഉത്തരം തെറ്റിയാൽ | ക്ലീൻ ബൗൾഡ് |
| ബൗളറുടെ ഉത്തരം തെറ്റിയാൽ | +1 എക്സ്ട്രാ (പന്ത് എണ്ണും) |

OPTIONAL = 10 സെക്കൻഡ്, ONE WORD = 1 മിനിറ്റ്, MINIMUM 3 SENTENCES = 3 മിനിറ്റ്, MINIMUM 5 SENTENCES = 5 മിനിറ്റ്, PICTURE IDENTIFYING = 5 മിനിറ്റ്.
